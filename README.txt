OFFLOAD - four files

  OFFLOAD-website.html         the website. "Try the app now" opens the household app inside it.
                               (index.html is a copy, so a website opens on it)
  OFFLOAD-household-app.html   the household app on its own
  OFFLOAD-manager-app.html     Manager app
  OFFLOAD-operations-app.html  Operations app

Every file works on phones and on desktop.
On the same website or in the same folder, all four share one set of demo data.

Recordings and heatmaps: round "Demo" button > "Research". Recording starts only after
the person taps "Allow recording". Typed text, emails and long numbers are never saved.
Microsoft Clarity is not switched on (needs your own project ID and your own website).
